# LaserStudio releases

Windows installers for **LaserStudio** by PrintingBrothers, laser design and control software.

- Download the latest installer from **Releases** (right side of this page).
- Installed copies of LaserStudio update themselves from here (Help > Check for updates…).
- LaserStudio needs an account: a 2-day free trial, then a yearly or lifetime licence.
  Buy or ask for help: call or WhatsApp **+91 93605 30028**.

This repository holds only installers and release notes. Each release's `latest.json` is signed by PrintingBrothers;
LaserStudio checks that signature and the installer's SHA-256 before installing anything.
